\begin{abstract}
Answering multi-hop questions over heterogeneous tables and unstructured text passages requires preserving tabular relational bindings while connecting cross-modal evidence from external passages. Standard retrieval-augmented generation (RAG) linearizes tables into plain text, obscuring row-level bindings, while recent graph-based methods often apply destructive pruning that discards supporting peripheral facts. In this work, we propose OUEG-RAG, a framework centered on \emph{explicit reasoning guidance over online knowledge graphs with diagnostic-driven retrieval feedback}. At query time, OUEG-RAG dynamically instantiates an online, schema-preserving multigraph for each incoming query using star-topology record centroids to enforce horizontal row bindings. Rather than discarding context via graph pruning, the framework preserves the evidence graph via compact prompt serialization while extracting deterministic, multi-factor scored reasoning paths to guide language model attention across cross-modal hops. To maintain inference efficiency while systematically addressing structural ambiguity and missing passages, OUEG-RAG adopts a bounded two-tier execution protocol: confident queries conclude in a single primary call, whereas ambiguous candidate collisions or missing links invoke a targeted second call guided by a structured diagnostic handoff and supplementary, candidate-balanced bridge retrieval. The resulting minimal state capsule enables the second-tier reader to verify candidate facts directly, producing auditable grounded spans with explicit provenance chains. Empirical evaluations across multi-hop table--text benchmarks demonstrate that this path guidance and targeted diagnostic feedback effectively improve grounding accuracy and reduce ungrounded answers while maintaining bounded query-time efficiency.

\keywords{Table question answering \and Knowledge graphs \and Retrieval-augmented generation \and Controlled reasoning \and Multi-hop grounding}
\end{abstract}

\section{Introduction}
Question answering over heterogeneous semi-structured tables and linked text passages requires navigating disparate data modalities~\cite{zhou2026tableqasurvey}. In multi-hop benchmarks such as HybridQA~\cite{hybridqa} and open table--text QA (OTT-QA), answering a query requires locating an entity within a table cell, traversing its external hyperlink to an unstructured passage (or vice-versa), and extracting a grounded answer span. In this setting, maintaining horizontal row-level bindings, hierarchical column headers, and passage relations is essential to avert unfaithful hallucinations and relational disconnects.

To capture these dependencies, recent retrieval-augmented generation (RAG) paradigms increasingly construct knowledge graphs (KGs) directly at query time~\cite{agarwal2025hybrid,peng2024graphragsurvey}. Pioneering works highlight two distinct design philosophies: On one end, zero-shot hybrid graph frameworks such as ODYSSEY~\cite{agarwal2025hybrid} construct query-time entity graphs and apply question-driven graph pruning to fit prompt budgets. On the other end, agentic GraphRAG frameworks such as HydraRAG~\cite{tan2025hydrarag} employ multi-turn LLM exploration loops and verification cycles over persistent knowledge bases. 

Despite their promises, empirical examination of these existing graph-based frameworks reveals three fundamental limitations that directly impede faithful multi-hop reasoning:
\begin{enumerate}
    \item \emph{Loss of Tabular and Semantic Bindings}: When tables and text are converted into graph triples (as in ODYSSEY), standard extraction decomposes records into isolated subject-predicate-object facts, stripping away hierarchical column headers and row-level context. Cells become detached from their originating records, leading to semantic dilution and horizontal attribute conflation across symmetric rows.
    \item \emph{Absence of Explicit Reasoning Guidance}: Existing methods typically feed the constructed graph (or a pruned subset of triples) into a language model as an unorganized collection of edges. Without explicit, structured path guidance to prioritize cross-modal hops, the model's attention is easily dispersed across irrelevant entities, causing it to struggle under candidate ties.
    \item \emph{The Dilemma of Destructive Pruning vs.\ Multi-Turn Overhead}: To navigate graph complexity, current frameworks face an unresolved trade-off: aggressive graph pruning (e.g., ODYSSEY) discards peripheral supporting facts (such as qualifying dates or secondary conditions), forcing the model into arbitrary guessing when candidates tie; conversely, agentic exploration loops (e.g., HydraRAG) incur substantial inference latency and repetitive LLM calls per query, while remaining unable to ingest ad-hoc, raw semi-structured tables dynamically.
\end{enumerate}

To address these challenges, we introduce \textbf{OUEG-RAG} (\textbf{O}nline \textbf{U}nified \textbf{E}vidence \textbf{G}raphs for \textbf{RAG}). Rather than treating the online graph as an unstructured pool of triples or relying on open-ended agent loops, OUEG-RAG preserves semantic relational bindings and establishes \emph{explicit reasoning guidance coupled with diagnostic-driven retrieval feedback}.

At query time, OUEG-RAG dynamically instantiates an online multigraph per query using star-topology record centroids $\rho_i$. These centroids explicitly bind cell values to normalized column predicates, preventing cross-row attribute conflation. Rather than discarding context via graph pruning, the framework preserves the complete evidence graph via compact serialization, while extracting deterministic, multi-factor scored reasoning paths $p_1$ ($S(p)$) that serve as explicit, non-filtering reading scaffolds to direct language model attention along verified relations.

Furthermore, OUEG-RAG bounds execution overhead through a controlled two-tier protocol:
\begin{itemize}
    \item \emph{Tier 1 (L1 Self-Audit \& Primary Call)}: The language model reads the complete multigraph guided by the scored path scaffold. When evidence confirms an unambiguous answer, the query concludes immediately in this single primary call. If structural ambiguity (such as multiple candidate rows satisfying the query) or a missing passage link is detected, the model defers generation and emits a structured \emph{diagnostic handoff packet}.
    \item \emph{Tier 2 (Diagnostic-Triggered Targeted Retrieval \& L2 Resolution)}: The diagnostic packet directs supplementary, candidate-balanced bridge retrieval exclusively for the competing focus rows. The resulting evidence is packaged into a minimal sufficient \emph{L2 State Capsule}, allowing the second-tier reader to verify candidate facts directly and resolve the bottleneck through factual evidence rather than heuristic tiebreaking.
\end{itemize}

Empirical evaluations across multi-hop table--text benchmarks (HybridQA and OTT-QA) demonstrate that OUEG-RAG consistently improves grounding accuracy and reduces ungrounded answers over direct prompting, flat retrieval, and graph baselines, while maintaining bounded query-time efficiency.

We articulate four principal contributions, aligned with the core tenets of our framework:
\begin{itemize}
    \item \textbf{Explicit Reasoning Guidance over Online Multigraphs}: A paradigm that reconciles query-time, schema-preserving multigraph construction with deterministic multi-factor path scoring ($S(p)$), steering language model attention along verified cross-modal relations without destructive evidence loss.
    \item \textbf{Preservation of Tabular Semantics}: A star-topology centroid formulation that explicitly maintains horizontal row bindings and normalized column headers, preventing cross-row attribute conflation in online table-to-graph conversion.
    \item \textbf{Diagnostic-Driven Retrieval Feedback}: A controlled handoff mechanism where structural collisions or missing links trigger targeted, candidate-balanced bridge retrieval, resolving bottlenecks factually rather than through heuristic tiebreaking.
    \item \textbf{Bounded Two-Tier Execution Protocol}: An adaptive inference design that concludes unambiguous queries in a single primary call while reserving a targeted second call for diagnostic-resolved states via a minimal sufficient state capsule $\mathcal{K}_{\text{L2}}$.
\end{itemize}

\section{Related Work}
\label{sec:related}

\input{figures/paradigm-comparison}

\paragraph{Hybrid Table--Text Question Answering and Graph Modeling.}
Multi-hop reasoning over heterogeneous tabular and textual knowledge was catalyzed by HybridQA~\cite{hybridqa} and open table--text benchmarks (OTT-QA). Early architectures tackled this challenge via supervised fine-tuning, combining coarse row retrieval with cross-modal neural readers (HYBRIDER~\cite{hybridqa}), multi-view attention mechanisms (MATE~\cite{eisenschlos2021mate}), or document-hopping retrieval (DocHopper~\cite{sun2021dochopper}). To model complex cross-modal connections, specialized graph frameworks constructed evidence graphs over rows, cells, and sentences (MuGER²~\cite{chen2022muger2}, S3HQA~\cite{lei2023s3hqa}) trained via graph neural networks (GNNs). While effective, these early systems fundamentally rely on task-specific parameter training over thousands of labeled examples, lacking zero-shot adaptability.

With the advent of instruction-tuned large language models, recent research has shifted toward zero-shot hybrid graph modeling. Most notably, ODYSSEY~\cite{agarwal2025hybrid} showed that an online entity graph can be constructed directly at query time from retrieved table cells and passages. However, ODYSSEY highlights two key limitations of existing online graphs: (1)~\emph{Loss of Tabular Semantics}: its relation extraction decomposes rows into isolated pairwise entity triples, discarding hierarchical column predicates and causing semantic dilution across symmetric rows; and (2)~\emph{Destructive Pruning without Guidance}: to fit LLM context limits, it prunes up to 53\% of graph elements based on question token similarity (Fig.~\ref{fig:paradigms}b). This aggressive filtering discards peripheral supporting evidence and leaves the remaining triples unorganized, forcing the model into arbitrary guessing when candidates tie. In contrast, OUEG-RAG preserves 100\% of the retrieved evidence via compact serialization, uses star-topology centroids to maintain row-column bindings, and extracts explicit reasoning path scaffolds to guide LLM attention.

\paragraph{Table Reasoning and Programmatic Decomposition with LLMs.}
As surveyed by Zhou et al.~\cite{zhou2026tableqasurvey}, language models have demonstrated strong tabular capabilities through symbolic code generation or task decomposition. Programmatic frameworks bind LLMs to SQL or Python interpreters (Binder~\cite{cheng2023binder}, TabSQLify), iteratively decompose queries into sub-questions (DATER~\cite{ye2023dater}), or progressively evolve table structures (Chain-of-Table~\cite{wang2024chainoftable}). Concurrently, TableRAG architectures~\cite{chen2024tablerag,yu2025tablerag} scale retrieval across large schemas. While programmatic execution excels at structured arithmetic over isolated clean tables, it falters in hybrid multi-hop settings where the critical reasoning step requires traversing unstructured text passages linked to table cells. Code interpreters cannot natively resolve fuzzy semantic transitions across free text without fragile ad-hoc prompts or multi-turn sandbox loops. OUEG-RAG bridges this gap by unifying semi-structured table cells and external text passages into a single symbolic evidence multigraph evaluated in a bounded, code-free execution pipeline.

\paragraph{Knowledge Graphs and Agentic GraphRAG Paradigms.}
Augmenting language models with structured knowledge graphs captures non-local multi-hop dependencies beyond the scope of surface lexical or dense retrieval, as demonstrated by QA-GNN~\cite{yasunaga2021qagnn}, JointLK~\cite{sun2022jointlk}, and G-Retriever~\cite{he2024gretriever}. In retrieval-augmented generation, Microsoft GraphRAG~\cite{edge2024graphrag} extracts open-domain entity triples using LLM prompting, which incurs heavy token costs and hallucinates phantom edges on tabular structures. 

More recently, HydraRAG~\cite{tan2025hydrarag} demonstrated the value of structured path guidance by coupling knowledge graphs with multi-factor verification cycles. However, HydraRAG highlights the inherent trade-offs of agentic GraphRAG: it relies on a pre-existing, persistent global knowledge base (e.g., Wikidata) and employs unbounded multi-turn agent loops (Fig.~\ref{fig:paradigms}c), incurring substantial inference latency and repetitive API calls. It cannot ingest ad-hoc, raw semi-structured tables dynamically at query time. OUEG-RAG addresses these limitations through an adaptive two-tier design: it instantiates an online multigraph per query in $<20$\,ms, provides explicit path guidance to direct attention, and resolves unambiguous queries in a single primary call, invoking a targeted second call only when diagnostic feedback identifies structural collisions or missing passages.

\section{The OUEG-RAG Framework}
\label{sec:method}

\input{figures/pipeline}

\subsection{Problem Formulation and Graph Representation}
\label{sec:formulation}
We formulate the task of multi-hop question answering over heterogeneous tabular and textual knowledge sources. An input instance is defined as a tuple $\mathcal{I} = (q, T, \mathcal{D}_T)$, where $q$ is a natural language question; $T = (C, R)$ is a semi-structured table comprising ordered headers $C = (c_1, \dots, c_m)$ and rows $R = \{r_1, \dots, r_n\}$ with discrete cells $v_{i,j}$; and $\mathcal{D}_T = \{d_1, \dots, d_K\}$ is the corpus of external text passages associated with $T$, where cell values link to passages via hyperlink mappings $\ell(v_{i,j}) \rightarrow d_k$. The objective is to extract the grounded answer span $a^* \in \mathcal{A}$ along with an auditable reasoning path $p^*$, where $a^*$ may reside as a table cell ($a^* = v_{i,j}$) or as an unstructured text span within a linked passage ($a^* \subset d_k$).

\paragraph{Online Evidence Multigraph Representation.}
Unlike persistent knowledge base settings that depend on static global entity graphs, table--text RAG requires synthesizing unstructured text with tabular structures on-the-fly. For each query $q$, we dynamically instantiate a bounded, query-specific directed multigraph $G_q = (V_q, E_q, \psi_V, \psi_E)$ whose node and edge sets are partitioned as:
\begin{equation}
\label{eq:graph-partition}
V_q = V_{\text{ent}} \cup V_{\text{rec}} \cup V_{\text{lit}}, \qquad
E_q = E_{\text{rec}} \cup E_{\text{attr}} \cup E_{\text{link}} \cup E_{\text{text}}.
\end{equation}
The node partition divides vertices by semantic abstraction:
\begin{itemize}[leftmargin=1.5em]
    \item $V_{\text{ent}}$: Named entity mentions extracted from linked table cells or passage text spans.
    \item $V_{\text{rec}} = \{\rho_i \mid r_i \in R\}$: Local star-topology record hub centroids, where each node $\rho_i = \texttt{table:}T\texttt{:row:}i$ uniquely anchors and binds all cell attributes of row $r_i$ to prevent cross-row attribute conflation.
    \item $V_{\text{lit}}$: Unlinked literal values (e.g., numbers, scores, dates, unlinked strings).
\end{itemize}
The edge set $E_q$ consists of directed relational facts $e = (h, r, t, \pi)$, where $h, t \in V_q$, $r$ is a normalized predicate, and $\pi = (\text{src\_id}, \text{row\_idx}, \text{col\_name})$ stores source provenance:
\begin{itemize}[leftmargin=1.5em]
    \item $E_{\text{rec}} = \{ (u_i, \texttt{has\_record}, \rho_i) \}$: Structural edges connecting row subject entity $u_i$ to its centroid hub $\rho_i$.
    \item $E_{\text{attr}} = \{ (\rho_i, \operatorname{norm}(H_j), v_{i,j}) \}$: Schema-level attribute edges from centroid $\rho_i$ to column cell values $v_{i,j}$.
    \item $E_{\text{link}} = \{ (v_{i,j}, \texttt{linked\_passage}, d_k) \}$: Cross-modal hyperlink edges connecting candidate cells to external Wikipedia passages.
    \item $E_{\text{text}}$: Intra-passage relational triples extracted from retrieved passage sentences.
\end{itemize}

\paragraph{Schema-Preservation and Non-Conflation Property.}
We define the intra-row star subgraph $\mathcal{G}^*(\rho_i) \subset G_q$ for row $r_i$ as:
\begin{equation}
\label{eq:star-subgraph}
\begin{aligned}
\mathcal{G}^*(\rho_i) = \Big( &\{\rho_i, u_i\} \cup \{v_{i,j}\}_{j=1}^m, \\
&\{(u_i, \texttt{has\_record}, \rho_i)\} \cup \{(\rho_i, \operatorname{norm}(H_j), v_{i,j})\}_{j=1}^m \Big).
\end{aligned}
\end{equation}
\begin{proposition}[Row Attribute Non-Conflation]
\label{prop:non-conflation}
For any distinct table rows $r_i, r_{i'} \in R$ ($i \neq i'$), their respective star-topology centroids are disjoint:
\begin{equation}
V(\mathcal{G}^*(\rho_i)) \cap V(\mathcal{G}^*(\rho_{i'})) \cap V_{\text{rec}} = \emptyset.
\end{equation}
Consequently, every cell value $v_{i,j}$ has a unique 1-hop path to its centroid $\rho_i$, mathematically precluding horizontal attribute conflation across rows.
\end{proposition}

Once question answering concludes, the dynamic multigraph $G_q$ is discarded, incurring zero persistent graph database index overhead. Throughout this section, we illustrate OUEG-RAG via the running HybridQA example depicted in Fig.~\ref{fig:pipeline}: \textit{``What was the original name of the city with an AFL club formed in 1989?''} (ground truth: \texttt{"York"}).

\subsection{Stage 1: Multi-Source Evidence Ingestion}
\label{sec:method-retrieval}
Benchmark settings supply an oracle table and an associated pool of linked passages. Retrieval operates dynamically within this context:
\begin{itemize}[leftmargin=1.5em]
    \item \emph{Coarse row retrieval and query anchoring}: A lexical retriever indexes table rows with respect to question $q$. A deterministic query anchor inspects $q$ for ordinal constraints (e.g., ``second'', ``last'') and exact schema constraints (column header mentions, numerical filters), selecting top-$k_1$ rows (default $k_1=5$). In Fig.~\ref{fig:pipeline}, the constraint ``formed in 1989'' anchors Row~0 (\texttt{Tor. Eagles}).
    \item \emph{Hyperlink passage expansion}: Rather than retrieving entire document corpora indiscriminately, the passage expander directly harvests Wikipedia hyperlinks (\texttt{linked\_passage} URLs) embedded in candidate cells of the top-$k_1$ retrieved rows up to a budget of $k_2$ passages (default $k_2=3$). In Fig.~\ref{fig:pipeline}, the bridge cell \texttt{Toronto} in Row~0 links to \texttt{Doc:Toronto}.
\end{itemize}

\subsection{Stage 2: Schema-Preserving Multigraph Construction}
\label{sec:method-kg}
Using the retrieved rows and passages, the system dynamically instantiates the multigraph $G_q=(V_q, E_q)$ in $<20$\,ms without LLM calls:
\begin{itemize}[leftmargin=1.5em]
    \item \emph{Centroid bindings}: For each candidate row $i$, local record centroid $\rho_i \in V_{\text{rec}}$ binds row attributes via $E_{\text{rec}}$ and $E_{\text{attr}}$ (Eq.~\ref{eq:star-subgraph}).
    \item \emph{Hyperlink bridging and deterministic text extraction}: Edges $E_{\text{link}}$ connect table cell entities to external passage nodes (e.g., $\text{Toronto} \to \text{Doc:Toronto}$). Rule-based text triples $E_{\text{text}}$ link entities to textual attributes (e.g., $\text{Doc:Toronto} \to \text{York}$) deterministically without LLM calls.
\end{itemize}

\subsection{Stage 3: Two-Tier Controlled Reasoning Engine}
\label{sec:method-engine}

\input{figures/diagnostic-l2}

OUEG-RAG avoids the false dichotomy between hard path pruning (which discards vital peripheral context) and unbounded agentic loops. Stage~3 coordinates four complementary mathematical components:

\paragraph{Information-Theoretic Prompt Compression.}
Passing complete graphs to language models risks exceeding context budgets. We formalize subgraph prompt compression as a lossless factorization operator $\mathcal{C}_{\text{oueg}}: G_q \rightarrow \mathcal{X}$, decomposing graph evidence into compact attribute maps and a shared passage dictionary:
\begin{equation}
\label{eq:compression}
\mathcal{X}^*(G_q) = \operatorname{Enc}_{\text{table}}\left(\{\mathcal{G}^*(\rho_i)\}_{i=1}^{k_1}\right) \;\oplus\; \operatorname{Enc}_{\text{text}}\left(\mathcal{S}_p\right),
\end{equation}
where $\mathcal{S}_p = \{ (d_k, \operatorname{text}(d_k)) \mid d_k \in \mathcal{D}_T \}$ indexes each external passage once by source ID. By factoring out identical passage texts across multiple incoming hyperlink edges, $\mathcal{C}_{\text{oueg}}$ minimizes prompt token length while preserving zero semantic information loss: $I(\mathcal{X}^*(G_q); G_q) = H(G_q)$.

\paragraph{Reasoning Path Space and Deterministic Multi-Factor Objective.}
A candidate multi-hop reasoning path $p \in \mathcal{P}_q$ of length $|E_p| = L \le 5$ is an alternating sequence of vertices and verified edges:
\begin{equation}
p = (v_0, e_1, v_1, e_2, \dots, e_L, v_L), \quad v_0 \in \operatorname{Seeds}(q), \; v_L \in \operatorname{Targets}(q), \; e_l \in E_q.
\end{equation}
To rank paths without expensive neural samplers, paths are scored via a deterministic linear combination of structural and semantic alignment features:
\begin{equation}
\label{eq:path-score}
S(p) = \mathbf{w}^\top \boldsymbol{\phi}(p, q, T) - \lambda_{\text{len}} \max(|E_p|-1, 0),
\end{equation}
where $\boldsymbol{\phi}(p, q, T) = [G, Q_e, Q_r, Q_c, C, M, R, B, A]^\top \in \mathbb{R}^9$ measures edge validity ($G=1.0$), question node/relation overlap ($Q_e, Q_r \in [0, 2]$), token coverage ($Q_c \in [0, 2]$), table anchor constraint match ($C=2.0$), cross-modal table-text fusion ($M=1.5$), row consistency ($R=1.0$), record binding ($B=1.0$), and corroboration ($A=1.0$), with $\lambda_{\text{len}}=0.35$ penalizing redundant hops. In Fig.~\ref{fig:pipeline}, the grounded path $p_1$ ($\text{Eagles} \rightarrow \rho_0 \rightarrow \text{Toronto} \rightarrow \text{York}$) achieves maximal score $S(p_1) = 7.85$.

\paragraph{Bounded Two-Tier Controlled Decision Process.}
Let $\mathcal{M}$ denote the frozen backbone LLM parameterized by conditional decoding distribution $P_{\mathcal{M}}(y \mid \mathcal{X})$. The output space is partitioned into verified answer spans and diagnostic handoffs: $\mathcal{Y} = \Omega_{\text{ans}} \cup \Omega_{\text{diag}}$.

At Tier 1 (L1), the model evaluates the prompt $\mathcal{X}_{\text{L1}} = \operatorname{Prompt}(q, \mathcal{X}^*(G_q), p_1)$, where $p_1 = \arg\max_{p \in \mathcal{P}_q} S(p)$ acts as a non-filtering reading guide. We define the candidate collision set $\mathcal{C}_q$ as the set of distinct target centroids sharing the maximal path score $S^* = \max_{p \in \mathcal{P}_q} S(p)$:
\begin{equation}
\label{eq:collision-set}
\mathcal{C}_q = \{ \operatorname{centroid}(p) \mid p \in \mathcal{P}_q, \, S(p) = S^* \}.
\end{equation}
The model's decoding behavior is governed by a strict decision rule:
\begin{enumerate}
    \item \emph{Determined State (Fast Exit)}: If $|\mathcal{C}_q| = 1$ and the traversal path $p_1$ is unbroken, the query is structurally determined. The model emits:
    \begin{equation}
    y_{\text{L1}} = \texttt{FINAL\_ANSWER: } a^*, \quad a^* = \arg\max_{a \in \mathcal{A}} P_{\mathcal{M}}(a \mid \mathcal{X}_{\text{L1}}),
    \end{equation}
    terminating execution in a single turn.
    \item \emph{Under-Determined State (Diagnostic Projection)}: If $|\mathcal{C}_q| > 1$ (candidate collision across symmetric rows) or a bridge passage link is missing, the query is structurally under-determined. The model is prohibited from arbitrary guessing and must emit a structured diagnostic projection:
    \begin{equation}
    \mathcal{H}_{\text{diag}} = \big( \mathcal{C}_{\text{focus}}, \, \beta, \, \psi_{\text{check}} \big) \in \Omega_{\text{diag}},
    \end{equation}
    where $\mathcal{C}_{\text{focus}} = \mathcal{C}_q$ denotes competing candidates, blocker $\beta$ classifies the failure type (such as collision or missing links), and $\psi_{\text{check}}$ specifies the unresolved factual predicate.
\end{enumerate}

\paragraph{Diagnostic-Triggered Targeted Bridge Expansion.}
When $\mathcal{H}_{\text{diag}}$ is emitted, the targeted retrieval operator $\mathcal{R}_{\text{target}}$ harvests missing candidate-linked passages exclusively for the focus set $\mathcal{C}_{\text{focus}}$:
\begin{equation}
\label{eq:targeted-retrieval}
\Delta \mathcal{D} = \bigcup_{c \in \mathcal{C}_{\text{focus}}} \left( \ell(c) \setminus \mathcal{D}_{\text{current}} \right), \quad \text{s.t.} \quad |\Delta \mathcal{D}_c| \le k_{\text{focus}},
\end{equation}
enforcing symmetric per-candidate passage budgets to maintain evidentiary balance.

\paragraph{Minimal Sufficient L2 State Capsule.}
The delta evidence is packaged into a minimal sufficient state capsule $\mathcal{K}_{\text{L2}}$:
\begin{equation}
\label{eq:l2-capsule}
\mathcal{K}_{\text{L2}} = \left( q, \, \psi_{\text{check}}, \, \{ \mathcal{G}^*(\rho_c) \}_{c \in \mathcal{C}_{\text{focus}}}, \, \Delta \mathcal{D} \right).
\end{equation}
\begin{proposition}[Informational Sufficiency of $\mathcal{K}_{\text{L2}}$]
\label{prop:sufficiency}
Conditioned on the unresolved check $\psi_{\text{check}}$ and focus candidates $\mathcal{C}_{\text{focus}}$, the capsule $\mathcal{K}_{\text{L2}}$ forms a sufficient statistic for the target answer $a^*$:
\begin{equation}
I(a^*; \mathcal{X}_{\text{L1}} \cup \Delta \mathcal{D} \mid \mathcal{K}_{\text{L2}}) = 0.
\end{equation}
\end{proposition}
By evaluating $\mathcal{K}_{\text{L2}}$ at Tier 2 (L2), the model resolves the question via:
\begin{equation}
a^* = \arg\max_{a \in \mathcal{A}} P_{\mathcal{M}}(a \mid \mathcal{K}_{\text{L2}}).
\end{equation}
Because $\mathcal{K}_{\text{L2}}$ provides the missing factual evidence $\Delta \mathcal{D}$ for all competing candidates, candidate symmetry is broken deterministically by verified ground truth, eliminating heuristic lexical tiebreaking.

\subsection{Stage 4: Grounded Generation and Provenance Audit}
\label{sec:method-answer}
Stage~4 outputs the verified answer span and exports an inspectable provenance homomorphism $\pi: a^* \rightarrow E_q^*$, mapping the answer back to traversed table coordinates (\texttt{AFL\_Ontario\_0:row:0}), bridge URLs (\texttt{/wiki/Toronto}), and passage text excerpts (\texttt{town of York (1793)}). If graph search disconnects, \emph{reverse grounding} synthesizes directly over retrieved evidence and maps the extracted span back onto $G_q$, avoiding empty failures.

\section{Experimental Protocol}
\label{sec:experiments}

\subsection{Benchmark and Evaluation Metrics}
We evaluate on the official 1,500-example stratified development benchmark sampled from HybridQA~\cite{hybridqa}. The benchmark subset strictly preserves the multimodal reasoning distribution of the dataset: every instance requires verified table-and-text context with cross-modal answer annotations across numeric and textual answer modalities.

We report three standard accuracy metrics: (1)~\emph{Exact Match (EM)}: strict string equality against gold reference after standard normalization; (2)~\emph{Token-level F1}: harmonic mean of precision and recall over word tokens; and (3)~\emph{Semantic Exact Match (Semantic EM)}: denotation equivalence under surface alias tolerance. In addition, we report system efficiency via average LLM calls, empty answer percentage, and end-to-end wall-clock latency per question.

\subsection{Baselines and Experimental Settings}
To ensure rigorous and fair comparative evaluation, all methods are evaluated across two open-weights model scales under matched retrieval pools ($k_1=5, k_2=3$), context limits (24,000 characters), and greedy decoding ($T=0$):
\begin{itemize}
    \item \emph{Direct LLM}: Zero-shot in-context prompting over linearized table rows and passages without graph structuring.
    \item \emph{Flat-RAG}: Standard concatenation of linearized table rows with raw retrieved text passages.
    \item \emph{ODYSSEY}~\cite{agarwal2025hybrid}: The published state-of-the-art zero-shot hybrid graph framework (NAACL 2025) employing question-driven destructive graph pruning.
    \item \emph{Path-Text Top-$N$}: Hard path filtering retaining only top-$N$ ranked reasoning paths while discarding the remainder of the multigraph.
    \item \emph{OUEG-RAG (Ours)}: The proposed controlled evidence scaffolding framework with two-tier diagnostic grounding.
\end{itemize}

\section{Results and In-Depth Analysis}
\label{sec:results}

\paragraph{Main benchmark results across model scales.}
Table~\ref{tab:main-results} presents the comparative evaluation across all 1,500 questions in the stratified development subset of HybridQA. Across both model regimes, OUEG-RAG achieves the highest grounding accuracy among evaluated methods. On 20B, OUEG-RAG reaches 56.47\% EM and 67.12\% F1 (+1.67\% EM, +2.45\% F1 over Direct LLM; +4.07\% EM over ODYSSEY). On 120B, OUEG-RAG reaches 61.40\% EM and 73.11\% F1 (+2.67\% EM, +3.41\% F1 over Direct LLM, McNemar $p = 0.0058 < 0.01$; +4.60\% EM over ODYSSEY).

The comparative results offer three key empirical observations:
First, \emph{Question-driven graph pruning can degrade accuracy}: Pruning the hybrid graph according to initial question matches yields 52.40\% EM on 20B and 56.80\% on 120B for ODYSSEY. In complex multi-hop queries, the critical factual span often resides in a cell or passage relation that does not directly match question keywords; pruning these peripheral edges removes relevant context from the prompt.
Second, \emph{Path-Text Top-$N$ hard filtering suffers substantial degradation}: Retaining only linear paths reduces EM to 21.20\% on 20B and 29.53\% on 120B. Because heuristic path ranking is imperfect, hard filtering eliminates valid candidates prematurely.
Third, \emph{OUEG-RAG achieves bounded efficiency}: By resolving clear queries at L1 (Fast Exit) and invoking L2 only when diagnostics indicate ambiguity or missing links, OUEG-RAG averages only 1.22--1.28 LLM calls per query, achieving competitive accuracy while bounding inference overhead.

\paragraph{Systematic component ablation analysis.}
Table~\ref{tab:ablation} systematically isolates the architectural pillars across 500 questions:
\begin{enumerate}
    \item \emph{Necessity of Diagnostic L2 Augmentation}: Disabling L2 augmentation requires L1 to infer answers without supplementary retrieval, dropping EM by $-1.60\%$ and increasing errors on collision queries.
    \item \emph{Necessity of Deterministic Path Scoring $S(p)$}: Replacing multi-factor scoring with unweighted path selection reduces EM by $-2.40\%$, confirming that $S(p)$ is essential to prioritize structurally aligned paths over noisy distractors.
    \item \emph{Graph Alone is Insufficient}: Supplying the complete multigraph without sequential path guidance drops EM by $-1.20\%$, indicating that explicit path scaffolds help steer attention across heterogeneous graphs.
    \item \emph{Impact of Hard Path Filtering}: Preserving only top-$N$ linear paths results in a substantial $-38.00\%$ EM drop (down to 18.00\%), indicating that discarding peripheral multigraph context forfeits relevant supporting facts.
    \item \emph{Prompt Compression is Required}: Disabling prompt deduplication drops EM by $-23.00\%$ and increases empty answers to 47.60\% due to token overflow.
\end{enumerate}

\paragraph{Human audit of provenance traces ($N=100$).}
A manual audit on 100 randomly sampled evaluation questions confirms: (1)~\emph{Trace Faithfulness}: In 92.0\% of cases, OUEG-RAG produced faithful reasoning chains where every traversed edge maps to verified cell coordinates or source Wikipedia passages; (2)~\emph{Bridge Alignment Precision}: In 89.0\% of cases, the multigraph path identified the ground-truth bridge entity linking the candidate row to external text; and (3)~\emph{Empty Failure Reduction}: On 120B, OUEG-RAG reduces empty failures to 0.53\% (compared to 3.40\% for ODYSSEY and 2.80\% for Path-Text).

\section{Limitations}
\label{sec:limitations}
First, query-time graph construction and richer structured prompts incur modest latency over naive direct prompting ($\approx 23\text{--}25$\,s vs.\ $\approx 6\text{--}10$\,s), though this is notably lower than multi-turn agentic systems. Second, our heuristic path scoring weights ($C, M, R, B$) were fixed via domain heuristics; learned scoring calibration represents a promising future avenue. Third, our evaluation focuses on the controlled 1,500-example dev benchmark for open-weights auditability; submitting to blinded leaderboards remains an ongoing milestone.

\section{Conclusion}
\label{sec:conclusion}
We presented OUEG-RAG, an online unified evidence graph framework for grounded table--text question answering. By uniting schema-preserving multigraphs with compact prompt compression, deterministic path scaffolding, and an adaptive two-tier diagnostic-driven execution protocol, OUEG-RAG mitigates the evidence loss of aggressive graph pruning while avoiding the multi-turn overhead of iterative agentic search. Evaluations across 20B and 120B open-weights models demonstrate consistent improvements in grounding accuracy and provenance faithfulness over direct prompting and graph pruning baselines.
