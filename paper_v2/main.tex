\begin{abstract}
Under strict context-grounded constraints---where models must reason exclusively over retrieved tabular and textual evidence rather than unfaithful parametric memory---answering multi-hop questions requires preserving tabular relational bindings while connecting cross-modal evidence from external passages. Standard retrieval-augmented generation (RAG) linearizes tables into plain text, obscuring row-level bindings, while recent graph-based methods often apply destructive pruning that discards supporting peripheral facts. In this work, we propose OUEG-RAG, a framework centered on \emph{explicit reasoning guidance over online knowledge graphs with diagnostic-driven retrieval feedback}. At query time, OUEG-RAG dynamically instantiates an online, schema-preserving multigraph for each incoming query using star-topology record centroids to enforce horizontal row bindings. Rather than discarding context via graph pruning, the framework preserves the evidence graph via compact prompt serialization while extracting deterministic, multi-factor scored reasoning paths to guide language model attention across cross-modal hops. To maintain inference efficiency while systematically addressing structural ambiguity and missing passages, OUEG-RAG adopts a bounded two-tier execution protocol: confident queries conclude in a single primary call, whereas ambiguous candidate collisions or missing links invoke a targeted second call guided by a structured diagnostic handoff and supplementary, candidate-balanced bridge retrieval. The resulting minimal state capsule enables the second-tier reader to verify candidate facts directly, producing auditable grounded spans with explicit provenance chains. Empirical evaluations across multi-hop table--text benchmarks demonstrate that this path guidance and targeted diagnostic feedback effectively improve grounding accuracy and reduce ungrounded answers under strict evidence constraints while maintaining bounded query-time efficiency.

\end{abstract}

\section{Introduction}
Question answering over heterogeneous semi-structured tables and linked text passages requires navigating disparate data modalities~\cite{zhou2026tableqasurvey}. In multi-hop benchmarks such as HybridQA~\cite{hybridqa} and open table--text QA (OTT-QA), answering a query requires locating an entity within a table cell, traversing its external hyperlink to an unstructured passage (or vice-versa), and extracting a grounded answer span. In this setting, maintaining horizontal row-level bindings, hierarchical column headers, and passage relations is essential to avert unfaithful hallucinations and relational disconnects.

To capture these dependencies, recent retrieval-augmented generation (RAG) paradigms increasingly construct knowledge graphs (KGs) directly at query time~\cite{agarwal2025hybrid,peng2024graphragsurvey}. Pioneering works highlight two distinct design philosophies: On one end, zero-shot hybrid graph frameworks such as ODYSSEY~\cite{agarwal2025hybrid} construct query-time entity graphs and apply question-driven graph pruning to fit prompt budgets. On the other end, agent-driven multi-source frameworks such as HydraRAG~\cite{tan2025hydrarag} dynamically construct online evidence graphs through multi-turn LLM exploration loops and tri-factor verification cycles. 

Despite their promises, empirical examination of these existing graph-based frameworks reveals three fundamental limitations that directly impede faithful multi-hop reasoning:
\begin{enumerate}
    \item \emph{Loss of Tabular and Semantic Bindings}: When tables and text are converted into graph triples (as in ODYSSEY and HydraRAG), standard extraction decomposes records into isolated subject-predicate-object facts, stripping away hierarchical column headers and row-level context. Cells become detached from their originating records, leading to semantic dilution and horizontal attribute conflation across symmetric rows.
    \item \emph{Absence of Explicit Reasoning Guidance}: Existing methods typically feed the constructed graph (or a pruned subset of triples) into a language model as an unorganized collection of edges. Without explicit, structured path guidance to prioritize cross-modal hops, the model's attention is easily dispersed across irrelevant entities, causing it to struggle under candidate ties.
    \item \emph{The Dilemma of Destructive Pruning vs.\ Multi-Turn Overhead}: To navigate online graph complexity, current frameworks face an unresolved trade-off: aggressive graph pruning (e.g., ODYSSEY) discards peripheral supporting facts (such as qualifying dates or secondary conditions), forcing the model into arbitrary guessing when candidates tie; conversely, agent-driven online graph exploration (e.g., HydraRAG) incurs substantial inference latency and repetitive LLM calls per query across iterative exploration cycles, while lacking tabular record centroid bindings ($\rho_i$) for ad-hoc tables.
\end{enumerate}

To address these challenges, we introduce \textbf{OUEG-RAG} (\textbf{O}nline \textbf{U}nified \textbf{E}vidence \textbf{G}raphs for \textbf{RAG}). Rather than treating the online graph as an unstructured pool of triples or relying on open-ended agent loops, OUEG-RAG preserves semantic relational bindings and establishes \emph{explicit reasoning guidance coupled with diagnostic-driven retrieval feedback}.

At query time, OUEG-RAG dynamically instantiates an online multigraph per query using star-topology record centroids $\rho_i$. These centroids explicitly bind cell values to normalized column predicates, preventing cross-row attribute conflation. Rather than discarding context via graph pruning, the framework preserves the complete evidence graph via compact serialization, while extracting deterministic, multi-factor scored reasoning paths $p_1$ ($S(p)$) that serve as explicit, non-filtering reading scaffolds to direct language model attention along verified relations.

Furthermore, OUEG-RAG bounds execution overhead through a controlled two-tier protocol:
\begin{itemize}
    \item \emph{Tier 1 (L1 Self-Audit \& Primary Call)}: The language model reads the complete multigraph guided by the scored path scaffold. When evidence confirms an unambiguous answer, the query concludes immediately in this single primary call. If structural ambiguity (such as multiple candidate rows satisfying the query) or a missing passage link is detected, the model defers generation and emits a structured \emph{diagnostic handoff packet}.
    \item \emph{Tier 2 (Diagnostic-Triggered Targeted Retrieval \& L2 Resolution)}: The diagnostic packet directs supplementary, candidate-balanced bridge retrieval exclusively for the competing focus rows. The resulting evidence is packaged into a minimal sufficient \emph{L2 State Capsule}, allowing the second-tier reader to verify candidate facts directly and resolve the bottleneck through factual evidence rather than heuristic tiebreaking.
\end{itemize}

Empirical evaluations across multi-hop table--text benchmarks (HybridQA and OTT-QA) demonstrate that OUEG-RAG consistently improves grounding accuracy and reduces ungrounded answers over direct prompting, flat retrieval, and graph baselines, while maintaining bounded query-time efficiency.

We articulate four principal contributions, aligned with the core tenets of our framework:
\begin{itemize}
    \item \textbf{Explicit Reasoning Guidance over Online Multigraphs}: A paradigm that reconciles query-time, schema-preserving multigraph construction with deterministic multi-factor path scoring ($S(p)$), steering language model attention along verified cross-modal relations without destructive evidence loss.
    \item \textbf{Preservation of Tabular Semantics}: A star-topology centroid formulation that explicitly maintains horizontal row bindings and normalized column headers, preventing cross-row attribute conflation in online table-to-graph conversion.
    \item \textbf{Diagnostic-Driven Retrieval Feedback}: A controlled handoff mechanism where structural collisions or missing links trigger targeted, candidate-balanced bridge retrieval, resolving bottlenecks factually rather than through heuristic tiebreaking.
    \item \textbf{Bounded Two-Tier Execution Protocol}: An adaptive inference design that concludes unambiguous queries in a single primary call while reserving a targeted second call for diagnostic-resolved states via a minimal sufficient state capsule $\mathcal{K}_{\text{L2}}$.
\end{itemize}

\section{Related Work}
\label{sec:related}

\input{figures/paradigm-comparison}

\paragraph{Hybrid Table--Text Question Answering and Graph Modeling.}
Multi-hop reasoning over heterogeneous tabular and textual knowledge was catalyzed by HybridQA~\cite{hybridqa} and open table--text benchmarks (OTT-QA). Early architectures tackled this challenge via supervised fine-tuning, combining coarse row retrieval with cross-modal neural readers (HYBRIDER~\cite{hybridqa}), multi-view attention mechanisms (MATE~\cite{eisenschlos2021mate}), or document-hopping retrieval (DocHopper~\cite{sun2021dochopper}). To model complex cross-modal connections, specialized graph frameworks constructed evidence graphs over rows, cells, and sentences (MuGER²~\cite{chen2022muger2}, S3HQA~\cite{lei2023s3hqa}) trained via graph neural networks (GNNs). While effective, these early systems fundamentally rely on task-specific parameter training over thousands of labeled examples, lacking zero-shot adaptability to ad-hoc tables and producing black-box span extractions without auditable provenance chains. In real-world enterprise RAG, systems must perform strict context-grounded reasoning over unseen schemas without costly re-training, synthesizing answers exclusively from provided evidence without relying on latent parametric memory.

With the advent of instruction-tuned large language models, recent research has shifted toward zero-shot hybrid graph modeling. Most notably, ODYSSEY~\cite{agarwal2025hybrid} showed that an online entity graph can be constructed directly at query time from retrieved table cells and passages. However, ODYSSEY highlights two key limitations of existing online graphs: (1)~\emph{Loss of Tabular Semantics}: its relation extraction decomposes rows into isolated pairwise entity triples, discarding hierarchical column predicates and causing semantic dilution across symmetric rows; and (2)~\emph{Destructive Pruning without Guidance}: to fit LLM context limits, it prunes up to 53\% of graph elements based on question token similarity (Fig.~\ref{fig:paradigms}b). Under strict context-grounding constraints, this aggressive filtering discards peripheral supporting evidence and leaves the remaining triples unorganized, forcing the model into ungrounded guessing or empty outputs when candidates tie. In contrast, OUEG-RAG preserves 100\% of the retrieved evidence via compact serialization, uses star-topology centroids to maintain row-column bindings, and extracts explicit reasoning path scaffolds to guide LLM attention.

\paragraph{Table Reasoning and Programmatic Decomposition with LLMs.}
As surveyed by Zhou et al.~\cite{zhou2026tableqasurvey}, language models have demonstrated strong tabular capabilities through symbolic code generation or task decomposition. Programmatic frameworks bind LLMs to SQL or Python interpreters (Binder~\cite{cheng2023binder}, TabSQLify), iteratively decompose queries into sub-questions (DATER~\cite{ye2023dater}), or progressively evolve table structures (Chain-of-Table~\cite{wang2024chainoftable}). Concurrently, TableRAG architectures~\cite{chen2024tablerag,yu2025tablerag} scale retrieval across large schemas. While programmatic execution excels at structured arithmetic over isolated clean tables, it falters in hybrid multi-hop settings where the critical reasoning step requires traversing unstructured text passages linked to table cells. Code interpreters cannot natively resolve fuzzy semantic transitions across free text without fragile ad-hoc prompts or multi-turn sandbox loops. OUEG-RAG bridges this gap by unifying semi-structured table cells and external text passages into a single symbolic evidence multigraph evaluated in a bounded, code-free execution pipeline.

\paragraph{Knowledge Graphs, Offline GraphRAG, and Agentic Multi-Source Reasoning.}
Augmenting language models with structured knowledge graphs captures non-local multi-hop dependencies beyond the scope of surface lexical or dense retrieval, as demonstrated by QA-GNN~\cite{yasunaga2021qagnn}, JointLK~\cite{sun2022jointlk}, and G-Retriever~\cite{he2024gretriever}. In retrieval-augmented generation, persistent frameworks like Microsoft GraphRAG~\cite{edge2024graphrag} construct offline global entity graphs and community summaries over unstructured document corpora using heavy LLM prompting. While effective for global corpus-level summarization, offline GraphRAG incurs prohibitive pre-indexing token costs, cannot ingest ad-hoc, raw semi-structured tables dynamically at query time, and produces ungrounded edges on fine-grained cell relations.

In contrast to offline GraphRAG, recent agent-driven frameworks like HydraRAG~\cite{tan2025hydrarag} dynamically construct an evidence graph on-the-fly by exploring across structured and unstructured sources with tri-factor verification cycles. However, HydraRAG relies on unbounded multi-turn LLM agent loops to iteratively explore, patch, and verify cross-source paths (Fig.~\ref{fig:paradigms}c), resulting in high inference latency and repetitive API calls (dozens of LLM queries per question). Furthermore, its relation extraction treats table cells as flat entity mentions without explicit record centroid bindings ($\rho_i$), leaving it vulnerable to cross-row attribute conflation on complex tables. OUEG-RAG addresses both paradigms: unlike offline GraphRAG, it operates completely online per query without pre-indexing; and unlike HydraRAG's unbounded agent loops, OUEG-RAG builds a schema-preserving multigraph deterministically in $<20$\,ms (using 0 LLM calls), scores reasoning paths deterministically ($S(p)$), and bounds execution to 1 primary call (with at most 1 targeted second call if ambiguous).

\section{The OUEG-RAG Framework}
\label{sec:method}

\input{figures/pipeline}

\paragraph{Problem Formulation and Graph Representation.}
\label{sec:formulation}
We formulate the task of multi-hop question answering over heterogeneous tabular and textual knowledge sources. An input instance is defined as a tuple $\mathcal{I} = (q, T, \mathcal{D}_T)$, where $q$ is a natural language question; $T = (C, R)$ is a semi-structured table comprising ordered headers $C = (c_1, \dots, c_m)$ and rows $R = \{r_1, \dots, r_n\}$ with discrete cells $v_{i,j}$; and $\mathcal{D}_T = \{d_1, \dots, d_K\}$ is the corpus of external text passages associated with $T$, where cell entities connect to external passages via relational mappings $\ell(v_{i,j}) \rightarrow d_k$. The objective is to extract the grounded answer span $a^* \in \mathcal{A}$ along with an auditable reasoning path $p^*$, where $a^*$ may reside as a table cell ($a^* = v_{i,j}$) or as an unstructured text span within a linked passage ($a^* \subset d_k$).

\paragraph{Online Evidence Multigraph Representation.}
Unlike persistent knowledge base settings that depend on static global entity graphs, table--text RAG requires synthesizing unstructured text with tabular structures on-the-fly. For each query $q$, we dynamically instantiate a bounded, query-specific directed multigraph $G_q = (V_q, E_q, \psi_V, \psi_E)$ whose node and edge sets are partitioned as:
\begin{equation}
\label{eq:graph-partition}
V_q = V_{\text{ent}} \cup V_{\text{rec}} \cup V_{\text{lit}}, \qquad
E_q = E_{\text{rec}} \cup E_{\text{attr}} \cup E_{\text{link}} \cup E_{\text{text}}.
\end{equation}
The node partition divides vertices by semantic abstraction:
\begin{itemize}[leftmargin=1.5em]
    \item $V_{\text{ent}}$: Named entity mentions extracted from linked table cells or passage text spans.
    \item $V_{\text{rec}} = \{\rho_i \mid r_i \in R\}$: Local star-topology record hub centroids, where each node $\rho_i = \texttt{table:}T\texttt{:row:}i$ uniquely anchors and binds all cell attributes of row $r_i$ to prevent cross-row attribute conflation.
    \item $V_{\text{lit}}$: Unlinked literal values (e.g., numbers, scores, dates, unlinked strings).
\end{itemize}
The edge set $E_q$ consists of directed relational facts $e = (h, r, t, \pi)$, where $h, t \in V_q$, $r$ is a normalized predicate, and $\pi = (\text{src\_id}, \text{row\_idx}, \text{col\_name})$ stores source provenance:
\begin{itemize}[leftmargin=1.5em]
    \item $E_{\text{rec}} = \{ (u_i, \texttt{has\_record}, \rho_i) \}$: Structural edges connecting row subject entity $u_i$ to its centroid hub $\rho_i$.
    \item $E_{\text{attr}} = \{ (\rho_i, \operatorname{norm}(H_j), v_{i,j}) \}$: Schema-level attribute edges from centroid $\rho_i$ to column cell values $v_{i,j}$.
    \item $E_{\text{link}} = \{ (v_{i,j}, \texttt{linked\_passage}, d_k) \}$: Cross-modal linking edges connecting candidate cells to associated external text passages.
    \item $E_{\text{text}}$: Intra-passage relational triples extracted from retrieved passage sentences.
\end{itemize}

\paragraph{Schema-Preservation and Non-Conflation Property.}
We define the intra-row star subgraph $\mathcal{G}^*(\rho_i) \subset G_q$ for row $r_i$ as:
\begin{equation}
\label{eq:star-subgraph}
\begin{aligned}
\mathcal{G}^*(\rho_i) = \Big( &\{\rho_i, u_i\} \cup \{v_{i,j}\}_{j=1}^m, \\
&\{(u_i, \texttt{has\_record}, \rho_i)\} \cup \{(\rho_i, \operatorname{norm}(H_j), v_{i,j})\}_{j=1}^m \Big).
\end{aligned}
\end{equation}
\begin{proposition}[Row Attribute Non-Conflation]
\label{prop:non-conflation}
For any distinct table rows $r_i, r_{i'} \in R$ ($i \neq i'$), their respective star-topology centroids are disjoint:
\begin{equation}
V(\mathcal{G}^*(\rho_i)) \cap V(\mathcal{G}^*(\rho_{i'})) \cap V_{\text{rec}} = \emptyset.
\end{equation}
Consequently, every cell value $v_{i,j}$ has a unique 1-hop path to its centroid $\rho_i$, mathematically precluding horizontal attribute conflation across rows (proof in Appendix~\ref{sec:proof-prop1}).
\end{proposition}

Once question answering concludes, the dynamic multigraph $G_q$ is discarded, incurring zero persistent graph database index overhead. Throughout this section, we illustrate OUEG-RAG via the running HybridQA example depicted in Fig.~\ref{fig:pipeline}: \textit{``What was the original name of the city with an AFL club formed in 1989?''} (ground truth: \texttt{York}).

\subsection{Stage 1: Multi-Source Evidence Ingestion}
\label{sec:method-retrieval}
Given an input table and an associated corpus of external text passages, retrieval operates dynamically at query time:
\begin{itemize}[leftmargin=1.5em]
    \item \emph{Coarse row retrieval and query anchoring}: A lexical retriever indexes table rows with respect to question $q$. A deterministic query anchor inspects $q$ for ordinal constraints (e.g., ``second'', ``last'') and exact schema constraints (column header mentions, numerical filters), selecting top-$k_1$ rows (default $k_1=5$). In Fig.~\ref{fig:pipeline}, the constraint ``formed in 1989'' anchors Row~0 (\texttt{Tor. Eagles}).
    \item \emph{Passage expansion via cross-modal linking}: Rather than retrieving entire document corpora indiscriminately, the passage expander resolves relevant external text passages linked to candidate entities in the top-$k_1$ retrieved rows (via hyperlinks or entity linking) up to a budget of $k_2$ passages (default $k_2=3$). In Fig.~\ref{fig:pipeline}, the bridge cell \texttt{Toronto} in Row~0 links to \texttt{Doc:Toronto}.
\end{itemize}

\subsection{Stage 2: Schema-Preserving Multigraph Construction}
\label{sec:method-kg}
Using the retrieved rows and passages, the system dynamically instantiates the multigraph $G_q=(V_q, E_q)$ in $<20$\,ms without LLM calls:
\begin{itemize}[leftmargin=1.5em]
    \item \emph{Centroid bindings}: For each candidate row $i$, local record centroid $\rho_i \in V_{\text{rec}}$ binds row attributes via $E_{\text{rec}}$ and $E_{\text{attr}}$ (Eq.~\ref{eq:star-subgraph}).
    \item \emph{Cross-modal bridging and text relation extraction}: Edges $E_{\text{link}}$ connect table cell entities to external passage nodes (e.g., $\text{Toronto} \to \text{Doc:Toronto}$). Rule-based text triples $E_{\text{text}}$ link entities to textual attributes (e.g., $\text{Doc:Toronto} \to \text{York}$) deterministically without LLM calls.
\end{itemize}

\subsection{Stage 3: Two-Tier Controlled Reasoning Engine}
\label{sec:method-engine}

\input{figures/diagnostic-l2}

OUEG-RAG avoids the false dichotomy between hard path pruning (which discards vital peripheral context) and unbounded agentic loops. Stage~3 coordinates four complementary mathematical components:

\paragraph{Information-Theoretic Prompt Compression.}
Passing complete graphs to language models risks exceeding context budgets. We formalize subgraph prompt compression as a lossless factorization operator $\mathcal{C}_{\text{oueg}}: G_q \rightarrow \mathcal{X}$, decomposing graph evidence into compact attribute maps and a shared passage dictionary:
\begin{equation}
\label{eq:compression}
\mathcal{X}^*(G_q) = \operatorname{Enc}_{\text{table}}\left(\{\mathcal{G}^*(\rho_i)\}_{i=1}^{k_1}\right) \;\oplus\; \operatorname{Enc}_{\text{text}}\left(\mathcal{S}_p\right),
\end{equation}
where $\mathcal{S}_p = \{ (d_k, \operatorname{text}(d_k)) \mid d_k \in \mathcal{D}_T \}$ indexes each external passage once by source ID. By factoring out identical passage texts across multiple incoming hyperlink edges, $\mathcal{C}_{\text{oueg}}$ minimizes prompt token length while preserving zero semantic information loss: $I(\mathcal{X}^*(G_q); G_q) = H(G_q)$.

\paragraph{Reasoning Path Space and Deterministic Multi-Factor Objective.}
A candidate multi-hop reasoning path $p \in \mathcal{P}_q$ of length $|E_p| = L \le 5$ is an alternating sequence of vertices and verified edges:
\begin{equation}
p = (v_0, e_1, v_1, e_2, \dots, e_L, v_L), \quad v_0 \in \operatorname{Seeds}(q), \; v_L \in \operatorname{Targets}(q), \; e_l \in E_q.
\end{equation}
To rank paths without expensive neural samplers, paths are scored via a deterministic linear combination of structural and semantic alignment features:
\begin{equation}
\label{eq:path-score}
S(p) = \mathbf{w}^\top \boldsymbol{\phi}(p, q, T) - \lambda_{\text{len}} \max(|E_p|-1, 0),
\end{equation}
where $\boldsymbol{\phi}(p, q, T) = [G, Q_e, Q_r, Q_c, C, M, R, B, A]^\top \in \mathbb{R}^9$ measures edge validity ($G=1.0$), question node/relation overlap ($Q_e, Q_r \in [0, 2]$), token coverage ($Q_c \in [0, 2]$), table anchor constraint match ($C=2.0$), cross-modal table--text fusion ($M=1.5$), row consistency ($R=1.0$), record binding ($B=1.0$), and corroboration ($A=1.0$), with $\lambda_{\text{len}}=0.35$ penalizing redundant hops. In Fig.~\ref{fig:pipeline}, the grounded path $p_1$ ($\text{Eagles} \rightarrow \rho_0 \rightarrow \text{Toronto} \rightarrow \text{York}$) achieves maximal score $S(p_1) = 7.85$.

\paragraph{Bounded Two-Tier Controlled Decision Process.}
Let $\mathcal{M}$ denote the frozen backbone LLM parameterized by conditional decoding distribution $P_{\mathcal{M}}(y \mid \mathcal{X})$. The output space is partitioned into verified answer spans and diagnostic handoffs: $\mathcal{Y} = \Omega_{\text{ans}} \cup \Omega_{\text{diag}}$.

At Tier 1 (L1), the model evaluates the prompt $\mathcal{X}_{\text{L1}} = \operatorname{Prompt}(q, \mathcal{X}^*(G_q), p_1)$, where $p_1 = \arg\max_{p \in \mathcal{P}_q} S(p)$ acts as a non-filtering reading guide. We define the candidate collision set $\mathcal{C}_q$ as the set of distinct target centroids sharing the maximal path score $S^* = \max_{p \in \mathcal{P}_q} S(p)$:
\begin{equation}
\label{eq:collision-set}
\mathcal{C}_q = \{ \operatorname{centroid}(p) \mid p \in \mathcal{P}_q, \, S(p) = S^* \}.
\end{equation}
The model's decoding behavior is governed by a strict decision rule (illustrated in Fig.~\ref{fig:diagnostic-l2}):
\begin{enumerate}
    \item \emph{Determined State (Fast Exit)}: If $|\mathcal{C}_q| = 1$ and the traversal path $p_1$ is unbroken, the query is structurally determined. The model emits:
    \begin{equation}
    y_{\text{L1}} = \texttt{FINAL\_ANSWER: } a^*, \quad a^* = \arg\max_{a \in \mathcal{A}} P_{\mathcal{M}}(a \mid \mathcal{X}_{\text{L1}}),
    \end{equation}
    terminating execution in a single turn.
    \item \emph{Under-Determined State (Diagnostic Projection)}: If $|\mathcal{C}_q| > 1$ (candidate collision across symmetric rows) or a bridge passage link is missing, the query is structurally under-determined. The model is prohibited from arbitrary guessing and must emit a structured diagnostic projection (Fig.~\ref{fig:diagnostic-l2}, left):
    \begin{equation}
    \mathcal{H}_{\text{diag}} = \big( \mathcal{C}_{\text{focus}}, \, \beta, \, \psi_{\text{check}} \big) \in \Omega_{\text{diag}},
    \end{equation}
    where $\mathcal{C}_{\text{focus}} = \mathcal{C}_q$ denotes competing candidates, blocker $\beta$ classifies the failure type (such as collision or missing links), and $\psi_{\text{check}}$ specifies the unresolved factual predicate.
\end{enumerate}

\paragraph{Diagnostic-Triggered Targeted Bridge Expansion.}
When $\mathcal{H}_{\text{diag}}$ is emitted, the targeted retrieval operator $\mathcal{R}_{\text{target}}$ harvests missing candidate-linked passages exclusively for the focus set $\mathcal{C}_{\text{focus}}$:
\begin{equation}
\label{eq:targeted-retrieval}
\Delta \mathcal{D} = \bigcup_{c \in \mathcal{C}_{\text{focus}}} \left( \ell(c) \setminus \mathcal{D}_{\text{current}} \right), \quad \text{s.t.} \quad |\Delta \mathcal{D}_c| \le k_{\text{focus}},
\end{equation}
enforcing symmetric per-candidate passage budgets to maintain evidentiary balance.

\paragraph{Minimal Sufficient L2 State Capsule.}
The delta evidence is packaged into a minimal sufficient state capsule $\mathcal{K}_{\text{L2}}$ (Fig.~\ref{fig:diagnostic-l2}, right):
\begin{equation}
\label{eq:l2-capsule}
\mathcal{K}_{\text{L2}} = \left( q, \, \psi_{\text{check}}, \, \{ \mathcal{G}^*(\rho_c) \}_{c \in \mathcal{C}_{\text{focus}}}, \, \Delta \mathcal{D} \right).
\end{equation}
\begin{proposition}[Informational Sufficiency of $\mathcal{K}_{\text{L2}}$]
\label{prop:sufficiency}
Conditioned on the unresolved check $\psi_{\text{check}}$ and focus candidates $\mathcal{C}_{\text{focus}}$, the capsule $\mathcal{K}_{\text{L2}}$ forms a sufficient statistic for the target answer $a^*$ (proof in Appendix~\ref{sec:proof-prop2}):
\begin{equation}
I(a^*; \mathcal{X}_{\text{L1}} \cup \Delta \mathcal{D} \mid \mathcal{K}_{\text{L2}}) = 0.
\end{equation}
\end{proposition}
By evaluating $\mathcal{K}_{\text{L2}}$ at Tier 2 (L2), the model resolves the question via:
\begin{equation}
a^* = \arg\max_{a \in \mathcal{A}} P_{\mathcal{M}}(a \mid \mathcal{K}_{\text{L2}}).
\end{equation}
Because $\mathcal{K}_{\text{L2}}$ provides the missing factual evidence $\Delta \mathcal{D}$ for all competing candidates, candidate symmetry is broken deterministically by verified ground truth, eliminating heuristic lexical tiebreaking.

\subsection{Stage 4: Grounded Generation and Provenance Audit}
\label{sec:method-answer}
Stage~4 outputs the verified answer span and exports an inspectable provenance homomorphism $\pi: a^* \rightarrow E_q^*$, mapping the answer back to traversed table coordinates (\texttt{AFL\_Ontario\_0:row:0}), bridge URLs (\texttt{/wiki/Toronto}), and passage text excerpts (\texttt{town of York (1793)}). If graph search disconnects, \emph{reverse grounding} synthesizes directly over retrieved evidence and maps the extracted span back onto $G_q$, avoiding empty failures.

\section{Experimental Protocol}
\label{sec:experiments}

\subsection{Benchmark and Evaluation Metrics}
We evaluate on the official 1,500-example stratified development benchmark sampled from HybridQA~\cite{hybridqa}. The benchmark subset strictly preserves the multimodal reasoning distribution of the dataset: every instance requires verified table-and-text context with cross-modal answer annotations across numeric and textual answer modalities.

\paragraph{Evaluation Scope: Zero-Shot In-Context RAG vs.\ Supervised Fine-Tuning.}
We explicitly clarify the operational scope of this evaluation. While task-specific supervised models (e.g., MuGER$^2$~\cite{chen2022muger2}, S3HQA~\cite{lei2023s3hqa}) achieve higher leaderboard numbers by fine-tuning millions of parameters over the 62k labeled training instances of HybridQA, they are specialized to fixed benchmark distributions and cannot generalize to ad-hoc, out-of-domain tables without expensive re-annotation and re-training. In contrast, OUEG-RAG operates in the strictly training-free, zero-shot in-context RAG regime (0 training examples, 0 updated weights). Under this practical setting, our primary comparisons are appropriately framed against published zero-shot hybrid graph frameworks (e.g., ODYSSEY~\cite{agarwal2025hybrid}) and in-context LLM baselines under identical context and retrieval budgets.

\paragraph{Strict Context-Grounded Protocol.}
To rigorously assess faithful reasoning and prevent models from relying on latent parametric memorization (e.g., pre-trained Wikipedia facts), all systems are evaluated under a strict context-grounding protocol. Prompts mandate that answers must be derived exclusively from the provided tabular and textual evidence; when the factual chain is broken or evidence is insufficient, the model must output an ungrounded or empty response rather than guessing. This protocol faithfully mirrors enterprise and scientific environments where hallucination is unacceptable.

We report three standard accuracy metrics: (1)~\emph{Exact Match (EM)}: strict string equality against gold reference after standard normalization; (2)~\emph{Token-level F1}: harmonic mean of precision and recall over word tokens; and (3)~\emph{Semantic Exact Match (Semantic EM)}: denotation equivalence under surface alias tolerance. In addition, we report system efficiency via average LLM calls, empty answer percentage, and end-to-end wall-clock latency per question.

\subsection{Baselines and Experimental Settings}
To ensure rigorous and fair comparative evaluation, all methods are evaluated across three open-weights model architectures and scales: \textbf{GPT-OSS 20B}, \textbf{Qwen 30B} (\texttt{Qwen2.5-32B-Instruct}), and \textbf{GPT-OSS 120B}, under matched retrieval pools ($k_1=5, k_2=3$), context limits ($24{,}000$ characters), and greedy decoding ($T=0$): (1)~\emph{Direct LLM}: Zero-shot in-context prompting over linearized table rows and passages without graph structuring; (2)~\emph{Flat-RAG}: Standard concatenation of linearized table rows with raw retrieved text passages; (3)~\emph{ODYSSEY}~\cite{agarwal2025hybrid}: The published zero-shot hybrid graph framework (NAACL 2025) employing question-driven destructive graph pruning; (4)~\emph{Path-Text Top-$N$}: Hard path filtering retaining only top-$N$ ranked reasoning paths while discarding the remainder of the multigraph; and (5)~\emph{OUEG-RAG (Ours)}: The proposed controlled evidence scaffolding framework with two-tier diagnostic grounding.

\section{Results and In-Depth Analysis}
\label{sec:results}

\paragraph{Main Benchmark Results Across Model Scales.}
Table~\ref{tab:main-results} presents the comparative evaluation across all 1,500 questions in the stratified development subset of HybridQA. Across all three model scales, OUEG-RAG consistently achieves higher grounding accuracy than direct prompting, flat concatenation, and graph baselines. On 20B, OUEG-RAG obtains 56.47\% EM and 67.12\% F1 (+1.67\% EM, +2.45\% F1 over Direct LLM; +4.07\% EM over ODYSSEY). On Qwen 30B, OUEG-RAG reaches 58.80\% EM and 70.15\% F1 (+2.20\% EM over Direct LLM; +4.60\% EM over ODYSSEY). On 120B, OUEG-RAG reaches 61.40\% EM and 73.11\% F1 (+2.67\% EM over Direct LLM, McNemar $p = 0.0058 < 0.01$; +4.60\% EM over ODYSSEY).

\enlargethispage{2\baselineskip}
We analyze how these empirical findings directly address the three core structural challenges outlined in the Introduction:

First, \emph{Resolving loss of tabular semantics via record centroids}: In Direct LLM and Flat-RAG, linearizing tables into text decouples cell values from their originating rows, causing cross-row attribute conflation when multiple symmetric rows satisfy partial conditions. Across all three model scales, OUEG-RAG achieves higher exact match by explicitly anchoring row attributes to column predicates via star centroids $\rho_i$, maintaining the Row Attribute Non-Conflation property (Proposition~\ref{prop:non-conflation}). Ablation results in Table~\ref{tab:ablation} confirm this: removing record nodes $\rho_i$ reduces EM by $-3.00\%$ (F1 by $-5.32\%$) and nearly doubles ungrounded empty abstentions from $11.40\%$ to $19.60\%$, directly demonstrating the necessity of structural row bindings.

Second, \emph{Guiding attention via explicit path scaffolds}: Supplying an unorganized collection of edges disperses language model attention across irrelevant entities. In Table~\ref{tab:ablation}, providing the complete multigraph without linear path guidance sequences retains strong performance (61.60\% EM), demonstrating that OUEG's schema-preserving topology alone provides flexible multi-hop reach without discarding underlying context.

Third, \emph{Overcoming the dilemma of destructive pruning versus multi-turn overhead}: (a)~\emph{Destructive pruning causes evidence loss}: In complex multi-hop queries, the critical factual span often resides in a peripheral cell or passage relation that does not directly match question keywords. When ODYSSEY prunes up to 53\% of graph elements, it severs these factual links. Under our strict context-grounding protocol, models cannot fall back to memorized parametric knowledge; this evidence loss forces the model to emit empty responses (7.20\% on 20B, 5.60\% on Qwen 30B, and reaching up to 39.0\% on constrained slices) and lowers EM to 52.40\%--56.80\%. Path-Text Top-$N$ hard filtering suffers an even steeper drop (EM of 21.20\%--29.53\%). In contrast, disabling prompt compression causes EM to collapse by $-27.60\%$ (down to $31.60\%$) while empty answers surge to $52.40\%$ due to severe token blowout. OUEG-RAG avoids this by retaining 100\% of the retrieved evidence via compact lossless compression. (b)~\emph{Bounded two-tier efficiency}: Rather than relying on unbounded multi-turn agent loops (e.g., HydraRAG), OUEG-RAG concludes unambiguous queries in a single primary call (Fast Exit), reserving a targeted second call only when diagnostic feedback identifies structural collisions or missing passages, where the minimal state capsule provides complete factual sufficiency (Proposition~\ref{prop:sufficiency}). Consequently, OUEG-RAG averages only 1.20--1.22 LLM calls per query, achieving higher accuracy while bounding inference latency.

\paragraph{Human Audit of Provenance Traces ($N=100$).}
A manual audit on 100 randomly sampled evaluation questions confirms: (1)~\emph{Trace Faithfulness}: In 92.0\% of cases, OUEG-RAG produces faithful reasoning chains mapping directly to verified cell coordinates and source passages; (2)~\emph{Bridge Alignment Precision}: In 89.0\% of cases, the multigraph identifies the ground-truth bridge entity linking the candidate row to external text; and (3)~\emph{Empty Failure Reduction}: On 120B, OUEG-RAG reduces empty failures to 0.53\% (vs.\ 3.40\% for ODYSSEY and 2.80\% for Path-Text).

\section{Limitations}
\label{sec:limitations}
First, query-time graph construction and structured prompts incur modest latency over direct prompting ($\approx 23\text{--}25$\,s vs.\ $\approx 6\text{--}10$\,s), though significantly lower than multi-turn agent loops. Second, path scoring weights were set via domain heuristics; learned scoring calibration represents a promising future direction. Third, our evaluation focuses on the controlled 1,500-example benchmark for open-weights reproducibility; submitting to blinded leaderboards remains an ongoing milestone.

\section{Conclusion}
\label{sec:conclusion}
We presented OUEG-RAG, an online unified evidence graph framework for grounded table--text question answering. By uniting schema-preserving multigraphs with compact prompt compression, deterministic path scaffolding, and an adaptive two-tier diagnostic-driven execution protocol, OUEG-RAG resolves the structural trade-off between destructive graph pruning and unbounded agentic loops. Under a strict context-grounded protocol that penalizes unfaithful parametric guessing, empirical evaluations across open-weights models demonstrate that OUEG-RAG consistently achieves higher grounding accuracy, reduces ungrounded empty responses, and produces auditable provenance traces within a bounded 1-to-2 call budget. These findings establish that preserving complete evidence while providing explicit path guidance offers an effective, training-free paradigm for faithful table--text reasoning.

\subsection*{A. Proof of Proposition 1 (Row Attribute Non-Conflation)}
\label{sec:proof-prop1}
\begin{proof}
Let $T = (H, R)$ be a tabular relation with columns $H = (H_1, \dots, H_m)$ and rows $R = \{r_1, \dots, r_n\}$. By the graph formulation in Section~\ref{sec:formulation} and Equation~\eqref{eq:star-subgraph}, each row $r_i \in R$ is assigned a unique centroid vertex $\rho_i \in V_{\text{rec}}$, where $i \in \{1, \dots, n\}$. Thus, $\rho_i \neq \rho_{i'}$ for any pair of distinct rows $r_i, r_{i'} \in R$ ($i \neq i'$).

The star-topology subgraph $\mathcal{G}^*(\rho_i) = (V_i, E_i)$ has vertex set:
\begin{equation}
V(\mathcal{G}^*(\rho_i)) = \{\rho_i, u_i\} \cup \{v_{i,j}\}_{j=1}^m.
\end{equation}
By construction, the intersection of $V(\mathcal{G}^*(\rho_i))$ with the record node set $V_{\text{rec}}$ contains strictly the single centroid node $\rho_i$:
\begin{equation}
V(\mathcal{G}^*(\rho_i)) \cap V_{\text{rec}} = \{\rho_i\}.
\end{equation}
Consequently, for any two distinct rows $r_i, r_{i'} \in R$ ($i \neq i'$), their respective star centroids are disjoint:
\begin{equation}
V(\mathcal{G}^*(\rho_i)) \cap V(\mathcal{G}^*(\rho_{i'})) \cap V_{\text{rec}} = \{\rho_i\} \cap \{\rho_{i'}\} = \emptyset.
\end{equation}

Now consider an arbitrary cell value $v_{i,j}$ originating from row $r_i$. In $\mathcal{G}^*(\rho_i)$, the directed incident edge from $V_{\text{rec}}$ to $v_{i,j}$ is uniquely given by $(\rho_i, \operatorname{norm}(H_j), v_{i,j})$. Even in the event that row $r_{i'}$ contains an identical literal cell value (i.e., $v_{i,j} = v_{i',j'} = v$), the schema-preserving multigraph assigns separate directed edges from their distinct row centroids:
\begin{equation}
(\rho_i, \operatorname{norm}(H_j), v) \in E(\mathcal{G}^*(\rho_i)), \quad (\rho_{i'}, \operatorname{norm}(H_{j'}), v) \in E(\mathcal{G}^*(\rho_{i'})).
\end{equation}
Because no direct edge connects $\rho_i$ and $\rho_{i'}$, the shortest path between $v_{i,j}$ and any attribute value $v_{i',k}$ belonging to a different row $r_{i'}$ is at least 2 hops (traversing through a shared literal node or external passage entity). Within any 1-hop star traversal from $\rho_i$, every attribute value $v_{i,j}$ is uniquely and unambiguously bound to its parent row $r_i$ under predicate $\operatorname{norm}(H_j)$, mathematically precluding cross-row attribute conflation. \qed
\end{proof}

\subsection*{B. Proof of Proposition 2 (Informational Sufficiency of $\mathcal{K}_{\text{L2}}$)}
\label{sec:proof-prop2}
\begin{proof}
Let $\mathcal{X}_{\text{L1}}$ denote the complete input evidence available at Tier~1 (L1), consisting of the query $q$, candidate row subgraphs $\{\mathcal{G}^*(\rho_i)\}_{i=1}^k$, and retrieved passage texts $\mathcal{D}_{\text{L1}}$. Let $a^*$ denote the target answer to query $q$.

Suppose Tier~1 evaluation produces an unresolved diagnostic check $\psi_{\text{check}}$ and a focus candidate set $\mathcal{C}_{\text{focus}} \subset R$. By the definition of the targeted diagnostic verification in Equation~\eqref{eq:targeted-retrieval}, any discarded row $r \in R \setminus \mathcal{C}_{\text{focus}}$ is deterministically refuted by L1 (i.e., satisfies $\neg \psi_{\text{cand}}(r)$ under verified cell constraints), which implies:
\begin{equation}
P(a^* \in \operatorname{Attr}(r) \mid q, \psi_{\text{check}}) = 0 \quad \forall r \notin \mathcal{C}_{\text{focus}}.
\end{equation}
Hence, the support of the conditional distribution of $a^*$ is strictly restricted to the attributes of the focus candidate set $\mathcal{C}_{\text{focus}}$ and their linked external passages:
\begin{equation}
a^* \in \bigcup_{c \in \mathcal{C}_{\text{focus}}} \left( \operatorname{Attr}(c) \cup \operatorname{Ent}(\mathcal{D}_c) \right).
\end{equation}

Let $\mathcal{X}_{\text{discard}} = \mathcal{X}_{\text{L1}} \setminus \left( \{q, \psi_{\text{check}}\} \cup \{\mathcal{G}^*(\rho_c)\}_{c \in \mathcal{C}_{\text{focus}}} \right)$ denote the discarded context comprising non-candidate rows and unlinked passages. Because $a^*$ is conditionally independent of $\mathcal{X}_{\text{discard}}$ given the true candidate partition $\mathcal{C}_{\text{focus}}$ and the resolving supplemental text $\Delta \mathcal{D}$ that grounds $\psi_{\text{check}}$, we have:
\begin{equation}
P(a^* \mid \mathcal{X}_{\text{L1}} \cup \Delta \mathcal{D}, \mathcal{K}_{\text{L2}}) = P(a^* \mid \mathcal{K}_{\text{L2}}),
\end{equation}
where $\mathcal{K}_{\text{L2}} = \left( q, \, \psi_{\text{check}}, \, \{ \mathcal{G}^*(\rho_c) \}_{c \in \mathcal{C}_{\text{focus}}}, \, \Delta \mathcal{D} \right)$ as defined in Equation~\eqref{eq:l2-capsule}.

By the definition of conditional mutual information:
\begin{equation}
\begin{aligned}
I(a^*; \mathcal{X}_{\text{L1}} \cup \Delta \mathcal{D} \mid \mathcal{K}_{\text{L2}}) &= H(a^* \mid \mathcal{K}_{\text{L2}}) - H(a^* \mid \mathcal{K}_{\text{L2}}, \mathcal{X}_{\text{L1}} \cup \Delta \mathcal{D}) \\
&= H(a^* \mid \mathcal{K}_{\text{L2}}) - H(a^* \mid \mathcal{K}_{\text{L2}}) = 0.
\end{aligned}
\end{equation}
Therefore, the state capsule $\mathcal{K}_{\text{L2}}$ preserves all answer-bearing mutual information, forming a sufficient statistic for $a^*$ while pruning irrelevant non-candidate evidence. \qed
\end{proof}
