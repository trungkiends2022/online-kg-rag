\caption{Two-tier controlled reasoning engine (Stage~3) structured as two parallel algorithmic blocks with deterministic graph compression, illustrated via the running AFL example. (Left) Tier~1 evaluates the lossless evidence graph representation. When candidate evidence is unambiguous, execution terminates via Fast Exit in a single LLM call ($\approx 80\%$ of queries). When candidate collision occurs (e.g., candidate clubs both matching 1989 where bridge evidence is missing), the LLM emits a structured diagnostic packet $\mathcal{D}$. (Center to Right) An automated zero-LLM search fetches targeted bridge passages (\texttt{Doc:Toronto\_Blues}) and executes algorithmic graph compression by pruning non-competing candidates to construct the minimal state capsule $\mathcal{S}_{\min}$. In Tier~2, the LLM resolves the ambiguity deterministically by factual evidence in a targeted second call (at most 2 calls total), producing the verified answer with verifiable provenance.}
